# KogenCredo checks

These 35 checks are explicitly enabled through `.credo.exs`; see
[the example configuration](configuration.md). This catalog describes version 0.1.0.
Each module documents its detection boundaries, examples and parameters.
Heuristic findings are advice, not proof that code is incorrect. Review findings
before deciding whether a check should fail your application's CI.

Parameters below are defaults, not a recommended policy for every application.
Checks requiring project-specific namespaces, paths, domains, codec modules or
allowed serial tests need those settings supplied deliberately.
